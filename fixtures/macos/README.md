# Synthetic macOS fixtures

Reconstructed from the macOS man pages and the open-source tool code (no Mac was available when the
macOS port was written, see docs/research/macos.md). Addresses are documentation ranges
(192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32) or the router defaults of this
project; MAC addresses are made up. Replace them with real captures (same file names) when
verifying on a Mac.
